# 素材清单与运行限制

这是从 V16 普通本机版整理的源码快照。原版游戏和售卖版没有被这个整理过程覆盖。

## 未包含的内容

| 类别 | 原工程位置 | 首批公开处理 |
| --- | --- | --- |
| 人物、建筑、卡牌、UI、贴图、模型 | `GodotProject/assets/` | 全部排除，保留资源引用；逐项公开授权尚未核验 |
| 字体 | `GodotProject/assets/fonts/` | 不随首批分发，运行需自行提供合法字体或改用默认字体 |
| 背景音乐与音效 | `GodotProject/assets/audio/` | 全部排除；原交付记录明确存在背景音乐分发授权待确认事项 |
| 售卖版与授权工具 | 独立售卖版工程 | 不包含 |
| 运行包、PCK、编辑器缓存、日志、个人存档 | 工程与用户数据目录 | 不包含 |

上述表格描述源码目录。GitHub Releases 另附 Windows 无背景音乐运行包，包含游玩所需美术、字体和短音效。运行包允许免费下载与个人游玩；不将其原创素材按 MIT 开源。第三方字体与资源的许可随包放在 `licenses/`。

音频管理器已移除原内置歌曲表，默认曲库为空，并支持玩家自行放入合法音乐。见 [添加音乐](MUSIC.md)。

作者确认本地版本曾使用 BTS 的音乐。本仓库不包含这些歌曲、伴奏或录音文件，也不授予任何相关音乐权利。程序代码的 MIT 许可不适用于它们。请勿将这些录音或包含它们的原游戏包上传到本仓库、Release 或公开下载服务。后续版本需要取得相应许可，或替换为允许游戏使用及再分发的原创/授权音乐。公开视频同样应使用合法配乐。

未把第三方资产统一标成 MIT。源码仓库缺失素材会使场景导入、运行或部分测试失败；普通玩家请使用 Release 运行包。

## 素材与源码复用

复用原游戏美术或文案需另获作者许可。自行设计内容和替换素材时，请保留第三方许可证与署名；不要从运行包提取素材并默认视为 MIT。

运行包第三方项目包括 Godot（MIT 与依赖许可）、Source Han Sans 和 Smiley Sans（OFL 1.1）、Kenney Car Kit（CC0）、Poly Haven 环境光与贴图（CC0）。详细来源见随包说明。原本机游戏与售卖版未被公开版制作覆盖。
