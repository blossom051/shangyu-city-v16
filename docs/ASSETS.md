# 素材清单与运行限制

这是从 V16 普通本机版整理的源码快照。原版游戏和售卖版没有被这个整理过程覆盖。

## 未包含的内容

| 类别 | 原工程位置 | 首批公开处理 |
| --- | --- | --- |
| 人物、建筑、卡牌、UI、贴图、模型 | `GodotProject/assets/` | 全部排除，保留资源引用；逐项公开授权尚未核验 |
| 字体 | `GodotProject/assets/fonts/` | 不随首批分发，运行需自行提供合法字体或改用默认字体 |
| 背景音乐与音效 | `GodotProject/assets/audio/` | 全部排除；原交付记录明确存在背景音乐分发授权待确认事项 |
| 售卖版与授权工具 | 独立售卖版工程 | 不包含 |
| 运行包、PCK、编辑器缓存、日志、个人存档 | 工程与用户数据目录 | 不包含 |

原音频管理器保留原始曲目 ID 和加载路径，仅用于说明程序结构；文件名与引用不代表这些音频已经获得公开分发许可。

未把来源不明的第三方资产统一标成 MIT，也未用占位图片冒充完整游戏。缺失资产会使场景导入、运行或部分测试失败；首批没有发布可直接玩的 Release。

## 后续可独立开展的工作

1. 逐项确认原创图像、第三方模型和字体的来源与再分发条件。
2. 用明确可分发的音乐替换授权未确认曲目。
3. 选择允许公开的资源，保留其原始许可证与署名。
4. 从干净克隆导入、实际运行并导出后，再考虑发布可玩的 Windows 包。
