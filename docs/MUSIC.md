# 自行添加背景音乐

公开版默认没有背景音乐，保留游戏音效。不添加音乐也可以正常游玩。

普通玩家：将合法取得的 `.mp3`、`.ogg` 或 `.wav` 文件放入运行包中、与 `ShangyuCity.exe` 相邻的 `music/` 文件夹，重启游戏即可。电台使用文件名作为曲目名，可以切换、静音和调整音量。只扫描文件夹第一层；不支持平台加密音乐、快捷方式或 URL 文件。

开发者：编辑器运行时使用 `GodotProject/music/`。`AudioManager.gd` 从该目录加载支持的文件，不再内置原商业歌曲的曲目表。曲库为空时，随机播放、切歌和续播会安全返回；音效不受影响。`GlobalMusicWidget.gd` 显示“未添加背景音乐”。

下载或购买音乐不自动等于可以随游戏公开再分发。分享自制版本时，请只附原创或拥有相应分发许可的音乐，并保留许可与署名。本项目不提供原 BTS 歌曲、伴奏或相关录音。
