# Windows 无背景音乐公开版检查

日期：2026-10-16。标签：v16.0.0-no-music。

## 本次通过

- 从独立公开构建目录导出 Windows x64 EXE + PCK，原本机游戏与售卖工程未被覆盖。
- 背景音乐三首 MP3 全部排除；构建资源中的音频只保留 30 个项目短 WAV 音效。空曲库时无背景音乐播放，随机播放与切歌不会发生空数组错误。
- 实际启动导出的 Windows 程序，在 NVIDIA RTX 5070 Ti / Vulkan 上进入主菜单、模式选择、城市地图与 HUD，并保存这三处实机画面。
- 同一运行包的 OpenGL 兼容模式也完成上述场景与音乐检查；该模式不支持部分 Forward+ 反射和抗锯齿效果，日志有对应提示。
- 外置 WAV 测试音乐加载、播放、静音、解除静音恢复均通过；测试音频位于独立 QA 目录，不随包发布。MP3/OGG 加载代码存在，但本次未分别听测。
- 分别启动两个导出程序进程，写入测试存档，再冷启动读取；回合 7 与现金 1234 等校验值一致。测试存档在独立 QA 目录，不随包发布。
- 当前完整构建工程的 AI 难度与经营事件测试 29 项通过。此结果不代表缺少素材的公开源码可直接运行这些测试。
- 字体、Godot、Kenney 与 Poly Haven 的许可/来源说明随包附带；没有私人存档、授权签发工具、密钥或商业歌曲文件。

## 导出方式与限制

本机标准 release 模板导出的程序发生原生启动崩溃；改用已实际验证的 Godot 4.7 debug 导出模板发布运行包。它仍是独立 EXE，不需要安装 Godot、不附编辑器，也不连接远程调试器。此选择不是对 release 崩溃根因已修复的声明。

日志仍有 shader cache 目录初始化警告，当前运行检查可完成；尚未验证其长期性能影响。当前验证不包括所有显卡、低配设备、长时间游玩、全部经济平衡或完整游戏回归，也未完成真实新玩家测试。未声称这些项目通过。

自动脚本通过游戏自身接口加载场景、读写测试存档和检查音乐状态；不把这些检查称为人工逐按钮验收或听感验收。
